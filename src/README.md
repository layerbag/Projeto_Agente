# `src/` — Módulos da aplicação

Pacote principal do projeto, organizado em submódulos por responsabilidade.

```
src/
├── agent/     # Agente conversacional com LangGraph + tools
├── chains/    # Exemplos de chains (referência)
├── mlops/     # Observabilidade: logging, métricas, tracing
├── rag/       # Core RAG: ingestão, vector store, sumarização, chain
└── utils/     # Utilitários gerais (PDF, YouTube, path, etc.)
```

Cada submódulo possui seu próprio `README.md` com detalhes.
